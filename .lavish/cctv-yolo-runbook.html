GOD'S EYE VIEW · CCTV WATCH

Run YOLO beside the app

The app already owns the integration: Node starts yolo_worker.py on the first scan, sends camera frames over stdin, and reads JSON detections from stdout. The missing piece is a Python environment, model weights, and two environment variables.

What happens at runtime

Live mode is also available through /api/cctv-analysis/live/:cameraId; snapshots come from the registered camera catalog, not arbitrary client URLs.

1

Install Python dependencies

From the repository root, create an isolated environment and install the worker requirements.

python3 -m venv .venv-yolo .venv-yolo/bin/python -m pip install -r server/providers/cctv-analysis/requirements.txt
2

Configure the app

Put these in the ignored .env file. This checkout already contains yolo26n.pt at the repository root.

CCTV_YOLO_PYTHON=/absolute/path/to/gods-eye-view/.venv-yolo/bin/python CCTV_YOLO_MODEL=/absolute/path/to/gods-eye-view/yolo26n.pt
3

Start cctv-watch

Restart the dev server after changing .env; the worker is launched lazily on the first scan.

npm run dev

Select a feed in CCTV WATCH, then choose RUN SCAN. Live streams scan automatically when enabled by the UI.

4

Verify the worker

Use the existing integration script with a real JPEG at /tmp/test_frame.jpg.

CCTV_YOLO_PYTHON="$PWD/.venv-yolo/bin/python" \ CCTV_YOLO_MODEL="$PWD/yolo26n.pt" \ node scripts/test-yolo-fast.mjs

Expected result

  • First scan may take longer while Ultralytics loads the model.
  • Node keeps one worker per Python/model pair and serializes requests.
  • The response has status: "ok", the model metadata, detections, tracks, events, and an assessment.
  • If variables are missing, the UI correctly reports model unavailable.

Common failures

  • python3 not found: use the absolute venv interpreter in CCTV_YOLO_PYTHON.
  • ModuleNotFoundError: install requirements using that same interpreter.
  • model not found: use an absolute path for CCTV_YOLO_MODEL.
  • camera_frame_unavailable: verify the feed is registered and reachable by the server.
  • scan_failed: inspect the terminal; the Python worker's stderr is intentionally not sent to the browser.

Relevant implementation points

yolo_worker.py reads newline-delimited JSON and emits newline-delimited JSON. scan.js resolves the environment variables, fetches registered-camera snapshots, and manages the child process. cctv-analysis.js mounts the scan and live endpoints. The browser surface is cctv-watch.html.
