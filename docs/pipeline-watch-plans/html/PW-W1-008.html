Add failure switches to replay scenarios

Work-item description

Allow a single scenario to exercise interrupted sources, retryable responses and duplicate delivery.

Acceptance Simulate latency, disconnects, duplicate callbacks, stale/unavailable sources, and additional dispatch outcomes and retryable failures.

Depends on PW-W1-007, PW-W1-012

Proposed execution steps

  1. Define named failure switches with a deterministic onset and recovery event.
  2. Apply each switch around replay or adapter boundaries while keeping the successful practice fixture reusable.
  3. Assert reproducible disconnect, delayed response and duplicate-callback cases after resetting the clock.
  4. Verify the proposed implementation with node --test src/pipelineWatch/testing/failures.test.mjs.
