Work-item description

Gather the evidence and monitoring readiness for one selected segment in one panel.

Depends on PW-W5-001, PW-W5-005

  3. Switch segments and test empty coverage, an offline camera and one linked incident.
  4. Verify the proposed implementation with node --test src/pipelineWatch/map/segmentDetails.test.mjs.
